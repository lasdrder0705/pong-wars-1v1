# Pong Wars 1v1 - 昼夜领地争夺战 (1v1 Battle Edition)

> 复刻并升级自推特爆火的 **Pong Wars**（作者 @vnglst / 分享者 @denicmarko），加入了 **大招激光格挡与后方保护、反冲吸收充能、黑白专属小球、接球能量偷取与减速博弈、5格石化要塞道具、3行挡板对齐激光大招与纯矢量 SVG 现代界面**。

---

## 🌟 核心机制升级

### 1. 大招激光挡板格挡与后方领地保护 (Laser Shielding & Rear Protection)
- **激光格挡判定**：敌方释放 3 行激光时，防守方可通过上下移动挡板拦截激光束。
- **后方领地完全保护**：激光在命中防守挡板表面时被强行阻断截断，**挡板后方的方格不会被激光同化**！
- **格挡大招反充奖励**：成功格挡敌方激光时，防守方瞬间吸收高能等离子，获得 **+30% 大招能量充能**！
- **专属格挡声光特效**：挡板亮起能量蜂窝护盾光弧，并在前沿产生密集能量冲击火花。

### 2. 纯正黑白小球二元对立
- **☀️ 昼方球**：深邃曜石黑 (#141414)，带有精细的高光暗弧；
- **🌙 夜方球**：纯净极光白 (#FFFFFF)，带有星芒白热光圈；
- 在任何速度与强化状态下，小球核心始终维持黑白对立标识。

### 3. 挡板接球博弈（能量偷取与减速惩罚）
- **偷取敌方大招能量**：己方挡板成功接住小球时，**偷取敌方 4% 能量**，并为己方充能 **+6%**。
- **敌方小球减速**：被挡板拦截的球速立即降低 **25%**（最低降至 0.5x 初速），随后随时间逐步加速。
- **速度与连破数量严格绑定**：
  - `速度 < 0.85x`（减速期/开局）：每次碰撞仅可击破 **1 个** 方格；
  - `0.85x ≤ 速度 < 1.25x`：每次碰撞可连续击破 **2 个** 方格；
  - `速度 ≥ 1.25x`（高速期）：每次碰撞可连续击破 **3 个** 方格。

### 4. 新增道具：5 格石化要塞 (Petrify Fortification)
- **拾取生成**：在敌方领地内随机挑选 5 个方块，瞬间同化为己方领地并赋予 **2 层石化护甲 (HP = 2)**。
- **要塞对抗规则**：
  - **低速/正常攻击 (连破 < 3)**：敌方需要连续击打 **2 次** 才能打破石化夺回领地。
  - **高速强冲 (连破 = 3)**：敌方高速球凭借强大动能**仅需击打 1 次**即可直接粉碎石化并反转领地，**但这 1 击会消耗全部穿透动能（连破数强制变为 1 并立即反弹）**。

### 5. 5 秒冷却普通技能（耀斑 / 月蚀）
- **独立冷却**：每 5 秒可释放一次（不消耗大招能量槽）。
- **精准敌方索敌**：算法遍历当前棋盘中属于**敌方的方格**，在其中随机选取坐标点引爆同化（3×3 范围）。
- **按键**：P1 (`E` 键) / P2 (`Right Shift` 键)。

### 6. 终极大招：挡板对齐 3 行等离子激光
- **大招效果**：以挡板当前高度为中心，射出贯穿全屏的 3 行激光束，瞬间将挡板对准的 **连续 3 整行方块全部转化为己方领地**！
- **按键**：P1 (`Space` 空格) / P2 (`Enter` 回车)。

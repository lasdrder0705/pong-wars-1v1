# 基于网格碰撞与领地争夺的双人实时对战游戏软件 V1.0

简称：**昼夜领地对战**。

本软件基于 Koen van Gilst 的开源作品 **Pong Wars**（MIT）进行独立扩展，新增双人挡板对战、局域网房间、技能与道具、Android 包装层和完整交互界面。第三方来源、版本及许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。软著申请应仅主张申请人独立完成的新增与改写部分，不应将上游或第三方组件申报为原创代码。

## 🌟 核心机制升级

### 1. 大招激光挡板格挡与后方领地保护 (Laser Shielding & Rear Protection)
- **激光格挡判定**：敌方释放 3 行激光时，防守方可通过上下移动挡板拦截激光束。
- **后方领地完全保护**：激光在命中防守挡板表面时被强行阻断截断，**挡板后方的方格不会被激光同化**！
- **格挡大招反充奖励**：成功格挡敌方激光时，防守方瞬间吸收高能等离子，获得 **+30% 大招能量充能**！
- **专属格挡声光特效**：挡板亮起能量蜂窝护盾光弧，并在前沿产生密集能量冲击火花。

### 2. 纯正黑白小球二元对立
- **☀️ 昼方球**：深邃曜石黑 (#141414)，带有精细的高光暗弧；
- **🌙 夜方球**：纯净极光白 (#FFFFFF)，带有星芒白热光圈；
- 在任何速度与强化状态下，小球核心始终维持黑白对立标识。

### 3. 挡板接球博弈（能量偷取与减速惩罚）
- **偷取敌方大招能量**：己方挡板成功接住小球时，**偷取敌方 4% 能量**，并为己方充能 **+6%**。
- **敌方小球减速**：被挡板拦截的球速立即降低 **25%**（最低降至 0.5x 初速），随后随时间逐步加速。
- **速度与连破数量严格绑定**：
  - `速度 < 0.85x`（减速期/开局）：每次碰撞仅可击破 **1 个** 方格；
  - `0.85x ≤ 速度 < 1.25x`：每次碰撞可连续击破 **2 个** 方格；
  - `速度 ≥ 1.25x`（高速期）：每次碰撞可连续击破 **3 个** 方格。

### 4. 新增道具：5 格石化要塞 (Petrify Fortification)
- **拾取生成**：在敌方领地内随机挑选 5 个方块，瞬间同化为己方领地并赋予 **2 层石化护甲 (HP = 2)**。
- **要塞对抗规则**：
  - **低速/正常攻击 (连破 < 3)**：敌方需要连续击打 **2 次** 才能打破石化夺回领地。
  - **高速强冲 (连破 = 3)**：敌方高速球凭借强大动能**仅需击打 1 次**即可直接粉碎石化并反转领地，**但这 1 击会消耗全部穿透动能（连破数强制变为 1 并立即反弹）**。

### 5. 5 秒冷却普通技能（耀斑 / 月蚀）
- **独立冷却**：每 5 秒可释放一次（不消耗大招能量槽）。
- **精准敌方索敌**：算法遍历当前棋盘中属于**敌方的方格**，在其中随机选取坐标点引爆同化（3×3 范围）。
- **按键**：P1 (`E` 键) / P2 (`Right Shift` 键)。

### 6. 终极大招：挡板对齐 3 行等离子激光
- **大招效果**：以挡板当前高度为中心，射出贯穿全屏的 3 行激光束，瞬间将挡板对准的 **连续 3 整行方块全部转化为己方领地**！
- **按键**：P1 (`Space` 空格) / P2 (`Enter` 回车)。

## 🚀 本地运行 / 局域网联机

电脑做主机（网页、手机浏览器、APK 都能连）：

```bash
npm test
node server.js
```

- 本机：`http://localhost:8080`
- 手机浏览器：终端打印的 `http://192.168.x.x:8080`
- **APK**：安装 `dist/pong-wars-1v1-debug.apk`，局域网联机里填电脑 IP，再创建/加入 4 位房间码

空格是昼方激光大招，**R** 重开，**P** 暂停。

## 🌍 公网域名部署

项目支持由 Nginx 终止 HTTPS/WSS，再反向代理到仅监听 `127.0.0.1:8080` 的单实例 Node 服务。若原域名已有网站，推荐使用独立子域名，例如 `game.example.com`，避免与原站点路径冲突。

生成仅含运行文件的服务器发布目录：

```bash
npm test
npm run package:server
npm run check:server-release
```

生产环境至少设置：

```ini
PORT=8080
GAME_BIND_HOST=127.0.0.1
GAME_PUBLIC_ORIGINS=https://game.example.com
```

完整 DNS、systemd、Nginx、证书、健康检查、验收和回滚步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。不要把整个仓库配置为 Web 静态目录；应部署 `dist/server-release/` 中的白名单运行包。

## 📱 Android APK

```bash
cd android && ./gradlew assembleDebug
```

产物：`android/app/build/outputs/apk/debug/app-debug.apk`

Android 应用使用受控的 `appassets.androidplatform.net` 本地资源域加载页面；为连接同一 Wi-Fi 内的电脑，仍保留局域网明文 `ws://` 能力。
